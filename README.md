# Attention Credit — Project Page V1

Static HTML/CSS research project page for GitHub Pages.

## Files

- `index.html` — page content and structure
- `style.css` — layout and styling
- `assets/` — reserved for real figures/plots

## Deploy with GitHub Pages

1. Upload these files to the `Gao01183/Attention-credit` repository.
2. In GitHub: **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. After deployment, open the Pages URL shown by GitHub.
